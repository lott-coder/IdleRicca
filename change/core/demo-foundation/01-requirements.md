# Demo 基础设施需求

## 背景与动机
为 IdleRicca 建立一个可直接进入 Play 的主场景和可复用的角色资产。

## 核心目标
- FR-01 使用 Mster 第一关 Room 作为构建入口。Mster 的整理工程中 Start 是启动引导，随后载入 Room。
- FR-02 使用 _ricca 的 Ricca 作为主角，选用哥布林、骷髅和地狱犬作为敌人。交付四个独立预制体以及各自的待机、移动和攻击动画。
- FR-03 采用项目内置渲染管线，场景与角色贴图可见，并在运行中检查光照、重叠面和动画。

## 验收标准
- Unity 可加载主场景，构建顺序首项为 Demo。
- 四种角色的 Mesh、骨骼、材质与动画资源完整，逐项验证动画实际驱动骨骼。
- Unity 运行截图看得到房间与人物，连续帧用于检查光影稳定性。
- 写入实际验证、问题处理和可复用迁移经验，再执行归档。

## 范围
场景与角色基础设施属于 core 的 Unity 资产与表现接入。战斗规则、敌人 AI、存档和原游戏运行时逻辑在需求范围之外。
