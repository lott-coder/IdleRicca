# City 迁移设计

> 在途契约终检：仅 core 在途，无模块冲突。

使用 Mster 整理工程的 City.unity。提取街道、建筑、道具、地形、背景、环境和道路装饰，保留网格子范围、LOD 与碰撞。按 Mster GUID 迁入所需材质、贴图和网格。URP 材质转换为 Built-in，保存颜色、贴图、法线、透明和发光设置。复用现有 Demo 场景路径和 GUID，并放置原有四个角色实例。采用室外固定光照与主相机。
原工程的玩法脚本、后处理与项目设置不随场景接入。独立 Unity 验证副本避免干扰已打开的 IdleRicca 编辑器。确认无 Room 引用后将旧素材移出 Assets，留本地备份。
