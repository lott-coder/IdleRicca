# 规格增量 - gameplay v0.0.1

## MODIFIED R5 — 剑身普攻和伤害

### 场景: 发动普通攻击
- 当 Ricca 存活、玩家按下左键且 Ricca 可以攻击
- 则 Application 接受一次普通攻击，Ricca 保持当前朝向并暂停水平移动，播放原有普通攻击动作，镜头可继续转动

### 场景: 结束普通攻击
- 当 普攻动画结束且 Ricca 存活
- 则 Application 解除移动和转身限制并继续处理当前 WASD 与 Shift

### 场景: 剑刃有效命中
- 当 有效普攻期间随剑刃运动的盒接触尚未被本次挥击命中的存活敌人
- 则 Application 对该敌人结算一次配置的普攻基础伤害与本局已选攻击增量之和，初始伤害配置为 25 HP。火焰充能期间按 R19 应用倍率

### 场景: 空挥、重复接触或非有效期接触
- 当 剑刃未接触敌人、已经在本次挥击命中过目标或处于非有效时间
- 则 Application 维持目标当前 HP

### 场景: Ricca 受击时已有普攻
- 当 Ricca 在普攻结束前受到有效伤害
- 则 Application 当次取消普攻，使尚未发生的命中失效

## MODIFIED R12 — 每波奖励三选一

### 场景: 通过一波
- 当 Ricca 存活且 Application 确认任一波通过
- 则 Application 保持当前波号并停止生成和战斗输入，给出一组三张有效奖励。City Demo 在三类都符合资格时，每张卡以 50% 概率抽取技能、25% 抽取普攻伤害、25% 抽取生命。抽到类型后从该类型尚未出现的等级中等概率选择，允许同类不同等级。没有可授予或升级技能或本局剩余 MP 低于 10 时，三张卡均按生命和普攻伤害各 50% 抽取。面板接管鼠标，第 10 波标记最后奖励

### 场景: 有效奖励选择
- 当 玩家选择当前组的一个有效选项且尚未结算、Ricca 存活
- 则 Application 结算一次。生命奖励同量增加当前与最大 HP，攻击奖励增加普攻伤害。两种加成在本局可叠加且等级越高增量越大。技能奖励执行 R14 的授予或升级并保留已有确认通知。第 1 至 9 波结算后前进一波

### 场景: 无效选择
- 当 玩家重复点击、索引越界、选择过期组或已经离开选择阶段
- 则 Application 维持当前属性、技能、波次和待选状态

### 场景: 旧场景奖励
- 当 不含技能运行配置的旧场景请求波次奖励
- 则 Application 沿用其既有权重与占位行为

## ADDED R19 — Blaze Charge 火焰充能

### 场景: 火焰充能生效
- 当 Ricca 完成 Blaze Charge 的施放动作，或该技能已经命中且清波使动作提前结束
- 则 Application 开启持续 20 个游戏秒的火焰充能。充能期间，普攻命中时将基础伤害与波次攻击奖励之和提高 20%，向下取整并以整数最大值为上限。Unity 将施放火焰留在剑身并随剑运动

### 场景: 充能期间再次完成施放
- 当 Ricca 在火焰充能期间再次成功触发充能
- 则 Application 从此次动作完成时重新计时 20 个游戏秒，维持单次 20% 普攻加成

### 场景: 结束火焰充能
- 当 充能到期、Ricca 死亡或场景卸载
- 则 Application 结束当前实例的充能，Unity 清除剑身火焰

### 场景: 在途施放取消
- 当 Blaze Charge 动作完成前取消且未触发清波结算
- 则 Application 维持原有充能状态及其剩余时长
