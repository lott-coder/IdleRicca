# 规格增量 - gameplay v0.0.1

## MODIFIED R5 — 剑身普攻和伤害

### 场景: 发动普通攻击
- 当 Ricca 存活、玩家按下左键且 Ricca 可以攻击
- 则 Application 接受一次普通攻击，Ricca 保持当前朝向并暂停水平移动，播放原有普通攻击动作，镜头可继续转动

### 场景: 结束普通攻击
- 当 普攻动画结束且 Ricca 存活
- 则 Application 解除移动和转身限制并继续处理当前 WASD 与 Shift

### 场景: 剑刃有效命中
- 当 有效普攻期间随剑刃运动的盒接触尚未被本次挥击命中的存活敌人
- 则 Application 对该敌人结算一次配置的普通攻击伤害，初始伤害配置为 25 HP

### 场景: 空挥、重复接触或非有效期接触
- 当 剑刃未接触敌人、已经在本次挥击命中过目标或处于非有效时间
- 则 Application 维持目标当前 HP

### 场景: Ricca 归零时已有普攻
- 当 Ricca 在普攻结束前归零
- 则 Application 当次取消普攻，使尚未发生的命中失效

## MODIFIED R6 — 三种敌人的场景生命值与受击动作

### 场景: 初始化敌人
- 当 Demo 成功生成哥布林、骷髅或地狱犬
- 则 Application 按该敌人独立的最大生命配置初始化 HP，三种敌人的初始配置均为 100 HP

### 场景: 受伤后仍存活
- 当 有效伤害命中敌人且敌人仍存活
- 则 Application 扣除相应 HP 并打断该敌人的在途攻击，进入受伤状态并播放对应动作

### 场景: 扣至零生命
- 当 有效伤害使敌人 HP 达到或低于 0
- 则 Application 将 HP 限制为 0，敌人当即退出战斗并关闭碰撞，播放对应死亡动作，播完后移除并释放生成名额

## ADDED R7 — 随机生成和场景数量上限

### 场景: 开场与随机补位
- 当 Demo 具备可用名额、存活的 Ricca 及合法位置
- 则 Application 允许在 Ricca 配置距离区间内的随机合法点生成敌人，默认上限 3，开场各类型优先，之后随机补位

### 场景: 无合法位置或已达上限
- 当 候选缺少地面、占位与模型或角色接触、无法沿完整路径到达 Ricca，或场景达到数量上限
- 则 Application 拒绝生成，计数包含尚未移除的死亡动画实例，并在后续允许的轮次再尝试

## ADDED R8 — 敌人追踪和自动出招

### 场景: 追踪
- 当 存活敌人可以行动、Ricca 存活且可沿场景路径追踪
- 则 Application 按双方距离和遮挡决定追踪，敌人移动时播放对应动作

### 场景: 近身攻击
- 当 Ricca 进入敌人配置攻击距离、攻击方向无遮挡且敌人可出招
- 则 Application 允许敌人停步、面向 Ricca 出招并播放对应动作，完整攻击结束先回待机并按配置进入冷却

## ADDED R9 — 敌人的攻击盒与 Ricca 生命

### 场景: 攻击命中 Ricca
- 当 存活敌人的攻击处于有效时段，攻击盒与存活的 Ricca 受击体接触且无遮挡
- 则 Application 对 Ricca 结算一次配置伤害，同一挥击后续接触不再扣血，其他角色 HP 维持原值

### 场景: 未形成有效命中
- 当 攻击被打断、Ricca 位于盒外、接触发生在窗口外或存在场景遮挡
- 则 Application 维持 Ricca 当前 HP

### 场景: Ricca 归零或重载
- 当 有效伤害使 Ricca HP 归零，或玩家重新加载 Demo
- 则 Application 在归零时停止移动与攻击并使敌人停止接敌，在重载时按初始配置恢复 Ricca HP 并重建生成状态
