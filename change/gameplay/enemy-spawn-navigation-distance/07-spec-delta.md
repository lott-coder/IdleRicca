# 规格增量 — gameplay/enemy-spawn-navigation-distance v0.0.1

## MODIFIED R7 — 随机生成和场景数量上限

### 场景: 开局与波内生成
- 当 Demo 处于战斗波、Ricca 存活、有剩余配额与实例名额、刷怪间隔已到且候选位置安全，从出生点到 Ricca 的完整导航路线长度在配置的距离区间内
- 则 Application 按该波配置接受生成，开局优先各生成一种现有敌人，之后随机，默认第 1 波上限 3

### 场景: 无合法位置、未到间隔或已达上限
- 当 候选缺少地面、占位与模型或角色接触、缺少完整导航路线、完整路线长度超出配置区间，或刷怪间隔未到、当前波配额已满、场上已达实例上限
- 则 Application 拒绝生成。实例名额包含尚未移除的死亡动画实例以及预约名额，在后续满足条件时可再次尝试

### 场景: 开始较低上限的新波
- 当 前一波尚未移除的死亡实例达到或超过新波实例上限
- 则 Application 在占用量低于该上限前拒绝新增，让已有死亡实例正常完成演出
