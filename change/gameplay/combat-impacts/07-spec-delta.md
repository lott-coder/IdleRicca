# 规格增量 — 战斗命中特效 v0.0.1

## ADDED R18 — Ricca 命中与受击粒子

### 场景: 普攻或主动技能打中敌人
- 当 Application 确认 Ricca 的普攻或任一主动技能对敌人造成伤害，包括致死命中
- 则 Application 返回该目标的命中结果，Unity 在接触位置为每个受伤目标播放一次蓝色命中粒子。技能原有的施放效果继续按原时序播放

### 场景: 敌方攻击打中 Ricca
- 当 Application 确认敌人的攻击使 Ricca 损失 HP，包括致死命中
- 则 Application 返回该次命中结果，Unity 在 Ricca 受击处播放一次可与蓝色命中特效区分的红色粒子

### 场景: 没有造成伤害
- 当 攻击落空、接触发生于有效窗口外、批次失效或同一攻击重复接触已命中的目标
- 则 Application 拒绝该次伤害报告，Unity 不播放新的命中或受击粒子
