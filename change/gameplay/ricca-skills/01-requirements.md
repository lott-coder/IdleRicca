# 需求文档 — Ricca 技能系统

## 背景与动机

City Demo 已有 Ricca 普攻、敌人受伤与死亡、十波战斗和三选一奖励。技能奖励目前提供类型和等级。本轮让玩家从波次奖励获得技能，在战斗中减速选招，并通过技能动作、特效和实际命中感受技能的差异。

## 核心目标

1. Ricca 每局有四个可查看的技能槽。波次奖励可以填入空槽，也可以在满槽后升级已装备技能。
2. 战斗中按 F 打开选择面板。有可施放技能时，战斗减速，玩家用鼠标点选后立即退出减速并施放。
3. 技能动作触发自己的伤害盒和生效窗口。有效碰撞进入现有敌人受伤、死亡和波次击败计数。

## 功能机制

| 编号 | 玩家行为与边界 | 层归属 |
|---|---|---|
| FR-1 | 新局显示四个空槽。选择有效的波次技能奖励后，有空槽时授予一个未装备的技能，填入序号最小的空槽。满槽后技能奖励升级一个尚可提升的已装备技能，在相同命中条件下，该技能升级后每次有效命中造成的配置伤害严格高于升级前。选择面板显示升级后的等级。学到的技能与等级仅在本局保留，重开回到四个空槽。 | Domain、Application、Presentation |
| FR-2 | 每次选中的技能奖励至多结算一次。已撤销、过期或重复提交的奖励维持技能状态。生成三选一时先排除无授予或升级对象的技能候选。全槽满级时由其他可用奖励组成三张有效卡。成功领取后才提交技能变化。末波技能卡遵循相同的结算规则，结算后进入通关。 | Domain、Application |
| FR-3 | Ricca 存活、处于可操控战斗阶段且能起手时，按 F 打开四槽面板并释放光标。至少有一项可施放技能时进入子弹时间。四槽皆空或无可施放项时仍可查看槽位，战斗保持打开面板前的速度。空槽和不可用槽显示禁用态。空槽面板提示技能来源和关闭按键，可用技能提供简短的攻击方向或范围提示。 | Application、Presentation |
| FR-4 | 点击当前可用槽位后，Application 接受一次施放。面板立即关闭，战斗速度恢复到开启前的值，Ricca 沿确认时的角色朝向播放该技能的动作。面板期间鼠标用于选择，移动和镜头输入暂时停止，选择点击同帧被隔离。F 或 Esc 可取消且无施放。施放期间保持起手朝向，新的普攻或技能请求不打断当前施放，也不排队。重复点击、过期槽位选择和不可施放状态均无效果。 | Application、Presentation |
| FR-5 | 领奖和终局界面优先接管输入。技能选择期间若失去焦点、Ricca 受到有效伤害、战斗阶段结束或场景卸载，选择退出并恢复子弹时间进入前的速度。受击或阶段退出会使在途技能后续命中失效。仍能继续战斗时，恢复操控按现有光标规则执行。 | Application、Presentation |
| FR-6 | 每项技能使用独立的动画、伤害量、盒形范围和生效窗口，部分技能同时播放原创特效。技能伤害只在生效窗口中与存活敌人的受击体有效接触时结算。同一次施放可命中多名敌人，对每个目标至多扣血一次。空挥、窗口外接触、重复接触及失效施放维持目标生命。有效命中沿用现有敌人受击和死亡流程。 | Domain、Application、Presentation |

## 目标用户

使用键盘和鼠标试玩 City Demo 的玩家。从首次波次技能奖励学会按 F 选招，在后续战斗中根据当前敌人的位置决定施放哪个技能。

## 成功标准

玩家可通过 Demo 正常入口，完成从空槽、选奖励、进入子弹时间、选招、命中并击败敌人，到填满四槽后继续升级的流程。重复选招和领奖、空挥、受击打断、通关和重开均按各自状态结算，时间与输入在退出选择后恢复。

## 约束条件

- 首版交付四个可通过波次奖励获取的原创占位技能，每项有独立动画和伤害盒，至少两项有原创占位特效。技能资产可在 Unity 中替换，片段、盒参数、生效时点及伤害等级可配置。
- 沿用现有十波进度、普通攻击判定和敌方生命模型。技能选择面板沿用当前场景 UI 入口，明确显示空槽、技能名称及等级。
- 伤害结算、技能可用状态和本局成长由本地 Application 写入。Unity 提供输入、动画进度、物理候选和特效表现。
- 参考当前 gameplay R5、R6、R9、R10、R11–R13。波次奖励 R12 的技能占位需在 Phase 2 通过规格增量更新。已落地的 `WaveRun.SkillRewardSelected` 提供类型和等级，授予身份和升级规则需纳入设计与验收。

## 引擎维度

- Windows PC 键鼠，Unity 2022.3.52f1c1，本地单机权威。
- 生命周期限于当前 Demo 局内，重开恢复初始四空槽，存档无字段或迁移变更。
- 选择面板开启或内容变化时刷新。战斗稳态 Update 和技能碰撞采样的托管分配目标为每帧 0 B，技能同屏实例和查询缓冲按既有波次容量验证。

## 方向方案（推荐 + 备选）

| 方案 | 做什么 | 取舍与前提 |
|---|---|---|
| A 点击后常速施放（本轮需求基线） | 按 F 进入选择，点击后立即恢复速度并按正常战斗节奏施放。 | 从动作和命中盒直接判断命中时机，覆盖空槽、取消、伤害打断和焦点切换。 |
| B 施放时延续子弹时间 | 点击后收起面板，维持减速直到技能演出结束。 | 强化演出，但会改变玩家闪避和敌方攻击节奏，并需要按技能约定减速退出点。 |

## 验收标准

| # | 验收项 | 证据级别 | 具体判据 |
|---|---|---|---|
| AC-1 | 奖励授予、升级与重开 | L1、L2 | 以固定奖励序列选择四次技能，按槽位顺序获得四个不同技能。再选一次，现有可升级技能之一提升且槽内技能身份不变。在等价的敌人状态和有效命中条件下，比较升级前后同一技能单次扣血，升级后严格增加。重复同一选择不会再次改变等级。全槽满级后，仍可收到三张有效卡。重开后四槽清空。 |
| AC-2 | 开启、取消与输入隔离 | L1、L2、L4 | 空槽时按 F 显示四槽且游戏速率不变。已有可用技能时按 F 释放光标并进入减速。移动鼠标、按移动键和点击空槽不会触发移动、转镜、普攻或技能。F 或 Esc 正常退出并恢复速率，点击有效技能只施放一次。截图记录空槽和有技能两态。 |
| AC-3 | 动作与特效 | L2、L4 | 逐个按 F 施放四个技能，记录各自触发的动画。至少两项显示原创占位特效，动画和特效时点与配置一致。 |
| AC-4 | 碰撞与波次击败 | L1、L2 | 至少构造盒外、窗口外、有效窗口双目标及单目标多碰撞体四种情况。两名有效目标各扣一次配置伤害。归零目标进入死亡且当前波击败计数加一。重复命中、同一施放内多个 Collider、非有效时点均无额外伤害。 |
| AC-5 | 安全退出和生命周期 | L1、L2 | 在面板打开时分别触发受击、失焦、奖励接管和场景卸载，核对每条路径的时间恢复。让 Ricca 在技能生效前受击，确认动作取消且后续无伤害。奖励、死亡、通关期间按 F 时技能面板不接管输入。 |
