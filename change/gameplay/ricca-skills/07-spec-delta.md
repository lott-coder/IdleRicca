# 规格增量 — Ricca 技能系统 v0.0.1

## MODIFIED R12 — 每波奖励三选一

### 场景: 通过一波
- 当 Ricca 存活且 Application 确认任一波通过
- 则 Application 保持当前波号，停止生成及战斗操作，提供一组固定的三张可选奖励。奖励按类型权重抽取，技能权重低于血量和攻击。组合以类型和等级唯一，同类不同等级可并存。接入技能系统的 City Demo 中，技能候选只在当前有可授予或可升级技能时参加抽取。未配置技能系统的旧场景保留原有占位候选。面板接管鼠标并在第 10 波标示最后奖励

### 场景: 有效奖励选择
- 当 玩家选择当前组三个有效选项中的一个，且当前组尚未结算、Ricca 存活
- 则 Application 至多结算一次。血量奖励同量增加当前和最大 HP，攻击奖励增加普攻伤害，两种加成可在本局叠加且高等级增量更大。接入技能系统的场景按 R14 授予或升级。未配置技能系统的旧场景结算原有占位。技能通知继续提供已选择的奖励类型和等级。第 1 至 9 波在结算后前进一波

### 场景: 无效选择
- 当 玩家重复点击、索引越界、选择过期组或已离开选择阶段
- 则 Application 拒绝本次选择，保留属性、技能、波次与待选状态

## ADDED R14 — 局内四个技能槽和奖励成长

### 场景: 开始一局
- 当 Demo 开始新局，包括死亡或通关后重开
- 则 Application 初始化四个空技能槽

### 场景: 奖励授予技能
- 当 当前局成功领取一张技能奖励且有空槽
- 则 Application 把按技能目录顺序取得的第一个未装备技能填入序号最小的空槽，初始等级等于本卡等级

### 场景: 满槽时升级
- 当 当前局成功领取一张技能奖励且四槽已满，存在未满级技能
- 则 Application 选择等级最低的技能，同级取槽位靠左的一项，至少提升一级，高等级卡可直升卡片等级，最高 Lv.3。该技能升级后在等价条件下每次有效命中伤害严格增加

### 场景: 槽位已全部满级
- 当 清波时四槽均已满级
- 则 Application 从仍有效的属性候选按既有组合约束抽取三张奖励

### 场景: 当前局死亡
- 当 Ricca 生命归零且 Application 裁定本局失败
- 则 Application 终止当前技能选择及施放，清除当前局技能状态

## ADDED R15 — 子弹时间技能选择

### 场景: 开启有可用技能的选择
- 当 Ricca 存活且可起手，处于可操控战斗阶段并按 F，存在可施放技能
- 则 Application 接受一次四槽选择，限制战斗输入并提供子弹时间状态。Unity 将战斗速率按默认倍率减至此前的 20%，玩家可用鼠标选择，敌人仍会慢速行动

### 场景: 开启空槽或无可施放技能的选择
- 当 Ricca 存活且可起手，处于可操控战斗阶段并按 F，当前没有可施放技能
- 则 Application 开启四槽查看状态，所有不可用槽禁用，战斗保持此前速率

### 场景: 点击可用技能
- 当 玩家点击当前选择会话中可用的一格，Ricca 存活且可起手
- 则 Application 接受且仅接受一次施放、关闭选择并释放减速状态。Unity 还原此前速率，按确认时的朝向播放技能动作，确认点击不触发普攻

### 场景: 取消或被打断
- 当 当前选择中按 F 或 Esc、失去焦点、Ricca 收到有效伤害、战斗阶段结束或场景卸载
- 则 Application 使当前选择失效，Unity 还原该次选择前的速率。重复或过期选择不启动动作，领奖和终局阶段维持其输入优先级

## ADDED R16 — 技能施放与盒形命中

### 场景: 技能表现
- 当 Application 接受一项技能施放
- 则 Application 提供施放标识和技能定义。Unity 播放该技能的独立动画，并在配置时点播放对应的可选原创特效

### 场景: 有效技能伤害
- 当 当前施放未失效且在配置生效窗口内，技能伤害盒和存活敌人受击体有效接触
- 则 Application 以本次施放的技能及等级扣除配置伤害。一次施放可伤害多个目标，但每个目标最多结算一次，归零纳入既有受伤、死亡及击败计数

### 场景: 空挥、重复接触或无效窗口
- 当 盒体无有效接触、已命中同一敌人、窗口外提交或批次已经失效
- 则 Application 维持目标 HP

### 场景: 施放中的输入与伤害打断
- 当 Ricca 正在施放且收到新的攻击意图，或者收到有效伤害或退出战斗
- 则 Application 拒绝在途期间新的普攻与技能请求。有效伤害或退出战斗立即取消在途施放并作废其未结算命中
