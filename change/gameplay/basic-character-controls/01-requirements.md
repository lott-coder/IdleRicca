# 需求文档：基础人物操作

> 模块：gameplay ｜ 子分类：basic-character-controls ｜ 版本：v0.0.1
> 日期：2026-11-22 ｜ 状态：已独立审核并获用户确认

## 背景与动机

Demo 已有 Ricca、哥布林、骷髅、地狱犬和可播放的角色动画。玩家进入构建首场景后，需要能转动视角、移动 Ricca，并用普通攻击实际击中敌人。

## 核心目标

1. 进入 Demo 后即可用键鼠控制跟随 Ricca 的第三人称镜头与角色移动。
2. Ricca 的行走、奔跑和普通攻击分别播放对应的现有动画。
3. 剑刃在有效挥击期间碰到敌人时扣血。每个敌人每次挥击最多扣一次。

## 功能机制

| 编号 | 功能 | 层归属 |
|---|---|---|
| FR-1 | Demo 默认进入第三人称。游戏窗口首次取得焦点后，自动把光标锁在中心并隐藏。鼠标横移调整镜头环绕角，纵移调整俯仰。相机跟随 Ricca。 | Presentation |
| FR-2 | WASD 相对镜头的水平朝向移动，Ricca 随移动方向转身。移动时松开 Shift 为行走，按住 Shift 为奔跑，奔跑实测位移速度高于行走。停止移动时回到待机。 | Application、Presentation |
| FR-3 | 点击鼠标左键，Ricca 沿角色当前朝向挥出一次普通攻击，并播放现有普通攻击动作。有效挥击期间，剑身碰撞盒随武器移动。每个接触的敌人每次挥击最多结算一次，新的挥击可以再次命中；空挥不会扣血。 | Domain、Application、Presentation |
| FR-4 | 普通攻击默认扣 25 HP，哥布林、骷髅和地狱犬各从 100 HP 开始。伤害和各敌人的初始 HP 在 Inspector 可调。HP 最低为 0，归零时立即隐藏并关闭其碰撞。重新进入场景恢复初始状态。 | Domain、Application、Presentation |

## 目标用户

在 PC 上通过键鼠试玩 Demo 的玩家。

## 成功标准

从构建首场景启动后，镜头能持续跟随并环绕 Ricca，行走和奔跑能在同一段移动中切换并播放对应动作。对初始 100 HP 的敌人完成四次有效的默认普攻时，目标在第四次命中后立即消失，再次进入场景即可重新测试。

## 约束条件

- 复用 Ricca 已有的行走 `rc_walk_loop`、奔跑 `rc_run_loop` 和普通攻击 `rc_stand_normalAttack_01`。
- 沿用现有 Demo 构建入口、主相机和四个角色预制体。城市迁移在 `core/city-main-scene` 单独进行，集成测试以迁移落地后的 Demo 为准。
- 敌人的 HP 和伤害结算由本地 Application 写入。Inspector 负责提供可调数据。配置字段的位置、代码与资源引用在 Phase 2 确定。
- 镜头、移动和连续挥击的稳态更新以每帧 0 B 托管分配为目标。

## 引擎维度

- 单机，本地权威。
- 增加本次场景生命值，重新载入场景初始化。无需存档分区或 schema 迁移。
- 目标平台为 Windows PC，使用键盘和鼠标。

## 方向方案（推荐 + 备选）

| 方案 | 行为 | 取舍 |
|---|---|---|
| A 随武器的命中盒（已选择） | 在有效挥击期间检查剑身与敌人接触。同一次挥击能命中接触到的多个敌人，并按目标去重。 | 需要校准剑身碰撞盒及生效时间，验证接触位置与实际动作一致。 |
| B 固定前方命中盒 | 在挥击有效帧检查 Ricca 前方区域。 | 判定体容易配置，攻击轨迹与剑身动作可能出现偏差。 |
| C 最近目标判定 | 在挥击有效帧检查前方区域，只选最近的盒内敌人。 | 目标选择确定，一次挥击的伤害只结算给一个敌人。 |

## 验收标准

| # | 验收项 | 证据级别 | 具体判据 |
|---|---|---|---|
| AC-1 | 第三人称跟随与光标 | L2、L3、L4 | 从构建首场景启动，游戏窗口首次取得焦点后，光标自动锁定并隐藏。横向和纵向输入都能改变镜头方向，移动时跟随点随 Ricca 更新。记录试玩画面。 |
| AC-2 | 镜头相对行走与奔跑 | L1、L2、L3 | 改变镜头水平角后，W 沿新前向移动；WASD 改变角色移动方向与朝向。移动中按住 Shift 时速度更高、播放奔跑，松开恢复速度和行走动作，停步后待机。 |
| AC-3 | 普攻和命中 | L1、L2、L3 | 转动镜头使其与 Ricca 朝向不同，左键触发现有普攻，角色保持起手朝向。剑刃有效接触处的目标扣血，处于角色前方但未接触剑刃的目标保持原 HP。同一挥击多次接触同一目标只扣一次，接触两个不同目标分别扣一次，离开有效时间后接触不会扣血。 |
| AC-4 | HP、消失和重载 | L1、L2 | 哥布林、骷髅、地狱犬默认各为 100 HP，任一目标连续四次有效命中后依次降到 75、50、25、0。到 0 当次关闭显示与碰撞，重进场景时三种敌人恢复初始值、显示与碰撞。修改 Ricca 的伤害与单个敌人的初始 HP 后，分别确认新伤害和新初始值生效，其他敌人的初始值保持原配置。 |

## 范围边界（明确不做）

- 攻击范围是现有单段普通攻击与生命值结算。
- 敌人行为、连击、受击和死亡动画、伤害浮字以及 HUD 以后单独规划。
