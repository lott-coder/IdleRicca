# 规格增量 — 右下角技能轮盘

## MODIFIED R13 — 波次、选技、奖励与结算的视觉提示

### 场景: 显示当前波次
- 当 Demo 提供当前波号
- 则 顶部居中的蓝金徽章以象牙白数字显示当前波号与总波数 X/10

### 场景: 查看技能槽
- 当 Ricca 打开选技界面
- 则 右下角的蓝金轮盘依次以上、右、下、左排列四个圆形槽位，战斗视图中央无遮挡且保持原亮度。有技能的槽位按技能 ID 显示图标、名称和等级，空槽显示空槽图标。缺蓝或资源不可用时，已装备的技能图标仍可辨认，按钮与图标以低亮度提示禁用

### 场景: 显示波次奖励
- 当 Demo 打开当前组三张奖励
- 则 生命卡显示心形，普攻伤害卡显示剑形，有具体技能的奖励卡与同技能的选择槽使用同一图案。第十波的最后奖励标题以暖金强调

### 场景: 显示本局结果
- 当 Demo 显示通关或失败结算
- 则 通关标题与分隔线以暖金强调，失败以暗红色系强调，两种状态共用蓝金重开按钮
