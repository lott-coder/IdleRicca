# 规格增量 — Demo 局内 UI 的蓝金样式与图标

## ADDED R13 — 波次、选技、奖励与结算的视觉提示

### 场景: 显示当前波次
- 当 Demo 提供当前波号
- 则 顶部居中的蓝金徽章以象牙白数字显示当前波号与总波数 X/10

### 场景: 查看技能槽
- 当 Ricca 打开选技面板
- 则 四个槽位保留 2×2 布局，有技能的槽位按技能 ID 显示对应图标，空槽显示空槽图标。缺蓝或资源不可用时，已装备的技能图标仍可辨认，按钮与图标以低亮度提示禁用

### 场景: 显示波次奖励
- 当 Demo 打开当前组三张奖励
- 则 生命卡显示心形，普攻伤害卡显示剑形，有具体技能的奖励卡与同技能的选择槽使用同一图标。第十波的最后奖励标题以暖金强调

### 场景: 显示本局结果
- 当 Demo 显示通关或失败结算
- 则 通关标题与分隔线以暖金强调，失败以暗红色系强调，两种状态共用蓝金重开按钮
