## R10 — Ricca 生命与蓝量（MODIFIED v0.0.1）

### 场景: 进入或重新载入 Demo
- 当 Demo 载入 Ricca 和战斗 HUD
- 则 Application 提供满额的 HP 与 MP，HP 和 MP 的默认初始值均为 100，HUD 左上显示两者的当前量与上限

### 场景: Ricca 实际受伤
- 当 已初始化的 Ricca 收到正伤害且 HP 大于 0
- 则 Application 扣除相应 HP，最低为 0，在同一结算中清空连击和续连窗口。HUD 同帧更新血条并隐藏连击，蓝条继续显示当前 MP

### 场景: 没有实际损失生命
- 当 Ricca 收到零或负伤害，或当前 HP 已为 0
- 则 Application 维持当前生命、蓝量和连击

### 场景: 施放接受与缺蓝
- 当 技能施放被接受或因当前 MP 不足被拒绝
- 则 Application 提供对应的当前 MP，HUD 使用快照更新蓝条。缺蓝时选择界面显示禁用的技能与 10 MP 成本提示

## R11 — 连击计数与 5 秒续连窗口

### 场景: 开始或延续连击
- 当 Ricca 对敌人结算一次有效普攻伤害
- 则 Application 在首击时置为 1，距上次有效命中不足 5 秒且生命未因受伤减少时加 1，从本次命中重新开始 5 秒计时

### 场景: 击杀、空挥和重复接触
- 当 同次挥击接触多个目标，或命中产生击杀，或发生空挥、重复接触及无效接触
- 则 Application 按既有普攻有效目标规则为每次成功结算的敌人伤害计 1。空挥、重复接触及无效接触不增加计数、不刷新计时

### 场景: 续连窗口结束
- 当 距上次有效命中达到 5 秒游戏时间且没有新的有效命中
- 则 Application 清空连击与续连窗口，同一时刻开始结算的下一击从 1 起算

## R12 — 连击显示

### 场景: 显示续连信息
- 当 Application 连击数达到 2 且续连窗口有效
- 则 Application 提供当前计数和剩余时间，HUD 在画面右侧显示数字与倒计时条，续连时更新数字、回满并给出短促强调

### 场景: 连击不可显示
- 当 进入 Demo、只有一次命中或连击因受伤或到期被清空
- 则 Application 提供小于 2 的计数，HUD 隐藏连击区域
