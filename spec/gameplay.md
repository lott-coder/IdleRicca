## R3 — Ricca 第三人称镜头

### 场景: 启动 Demo 并取得焦点
- 当 玩家进入构建首场景且游戏窗口首次取得焦点
- 则 本地运行启用跟随 Ricca 的第三人称主相机，锁定并隐藏鼠标光标

### 场景: 转动视角
- 当 玩家在操控状态移动鼠标
- 则 本地运行更新第三人称相机的水平环绕和俯仰并继续跟随 Ricca

## R4 — Ricca 行走与奔跑

### 场景: 镜头相对移动
- 当 玩家按 WASD 且 Ricca 可移动
- 则 Application 按镜头的水平朝向生成移动意图，Ricca 向移动方向转身并播放对应的移动动画

### 场景: 切换奔跑
- 当 Ricca 正移动且玩家按住或松开 Shift
- 则 Application 在奔跑和行走之间切换，Ricca 以对应速度移动并播放原有奔跑或行走动画

## R5 — 剑身普攻和伤害（MODIFIED v0.0.1）

### 场景: 发动普通攻击
- 当 Ricca 存活、玩家按下左键且 Ricca 可以攻击
- 则 Application 接受一次普通攻击，Ricca 保持当前朝向并暂停水平移动，播放原有普通攻击动作，镜头可继续转动

### 场景: 结束普通攻击
- 当 普攻动画结束且 Ricca 存活
- 则 Application 解除移动和转身限制并继续处理当前 WASD 与 Shift

### 场景: 剑刃有效命中
- 当 有效普攻期间随剑刃运动的盒接触尚未被本次挥击命中的存活敌人
- 则 Application 对该敌人结算一次配置的普攻基础伤害与本局已选攻击增量之和，初始伤害配置为 25 HP

### 场景: 空挥、重复接触或非有效期接触
- 当 剑刃未接触敌人、已经在本次挥击命中过目标或处于非有效时间
- 则 Application 维持目标当前 HP

### 场景: Ricca 受击时已有普攻
- 当 Ricca 在普攻结束前受到有效伤害
- 则 Application 当次取消普攻，使尚未发生的命中失效

## R6 — 三种敌人的场景生命值与受击动作（MODIFIED v0.0.1）

### 场景: 初始化敌人
- 当 Demo 成功生成哥布林、骷髅或地狱犬
- 则 Application 按该敌人独立的最大生命配置初始化 HP，三种敌人的初始配置均为 100 HP

### 场景: 受伤后仍存活
- 当 有效伤害命中敌人且敌人仍存活
- 则 Application 扣除相应 HP 并打断该敌人的在途攻击，进入受伤状态并播放对应动作

### 场景: 扣至零生命
- 当 有效伤害使敌人 HP 达到或低于 0
- 则 Application 将 HP 限制为 0，敌人当即退出战斗并关闭碰撞，播放对应死亡动作，播完后移除并释放生成名额

## R7 — 随机生成和场景数量上限（MODIFIED v0.0.1）

### 场景: 开局与波内生成
- 当 Demo 处于战斗波、Ricca 存活、有剩余配额与实例名额、刷怪间隔已到且位置合法
- 则 Application 按该波配置接受生成，开局优先各生成一种现有敌人，之后随机，默认第 1 波上限 3

### 场景: 无合法位置、未到间隔或已达上限
- 当 候选缺少地面、占位与模型或角色接触、无法沿完整路径到达 Ricca，或刷怪间隔未到、当前波配额已满、场上已达实例上限
- 则 Application 拒绝生成。实例名额包含尚未移除的死亡动画实例以及预约名额，在后续满足条件时可再次尝试

### 场景: 开始较低上限的新波
- 当 前一波尚未移除的死亡实例达到或超过新波实例上限
- 则 Application 在占用量低于该上限前拒绝新增，让已有死亡实例正常完成演出

## R8 — 敌人追踪和自动出招

### 场景: 追踪
- 当 存活敌人可以行动、Ricca 存活且可沿场景路径追踪
- 则 Application 按双方距离和遮挡决定追踪，敌人移动时播放对应动作

### 场景: 近身攻击
- 当 Ricca 进入敌人配置攻击距离、攻击方向无遮挡且敌人可出招
- 则 Application 允许敌人停步、面向 Ricca 出招并播放对应动作，完整攻击结束先回待机并按配置进入冷却

## R9 — 敌人的攻击盒与 Ricca 生命（MODIFIED v0.0.1）

### 场景: 攻击命中 Ricca
- 当 存活敌人的攻击处于有效时段，攻击盒与存活的 Ricca 受击体接触且无遮挡
- 则 Application 对 Ricca 结算一次配置伤害，Ricca 仍存活时播放普通受击动作，同一挥击后续接触不再扣血，其他角色 HP 维持原值

### 场景: 未形成有效命中
- 当 攻击被打断、Ricca 位于盒外、接触发生在窗口外或存在场景遮挡
- 则 Application 维持 Ricca 当前 HP

### 场景: Ricca 归零
- 当 有效伤害使 Ricca HP 归零
- 则 Application 停止移动与攻击、刷怪及敌人接敌，结束本局并将波号重置为 1，清除本局加成和待选奖励。Ricca 播放一次死亡动画，之后显示本局结束与重新开始按钮

### 场景: 重载 Demo
- 当 玩家点击有效的重新开始按钮或重新加载 Demo
- 则 Application 让新一局从第 1 波、初始位置和配置生命开始，重置生成、连击、奖励与普通攻击数值

## R10 — 受击双方的短暂减速

### 场景: 有效普攻命中
- 当 Application 确认 Ricca 的普攻给敌人造成伤害
- 则 Ricca 和被命中的敌人以配置倍率减速，按不受全局时间缩放影响的时钟计时，到期恢复各自的原播放速度。镜头和其他敌人照常更新

### 场景: 连续命中与同帧多目标
- 当 Application 在卡肉期间确认新的有效命中
- 则 Ricca 与新命中目标分别从该次命中重新计时。同帧给多个目标造成伤害时，Ricca 使用一次配置时长，每名目标独立减速

### 场景: 空挥或重复碰撞
- 当 普攻未造成新的伤害，包括空挥或同一挥击的重复接触
- 则 Application 维持原结算结果，角色播放使用既有的卡肉时钟

### 场景: 致死命中
- 当 Application 确认普攻使敌人生命归零
- 则 敌人退出战斗、关闭碰撞并减速播放死亡动作开头，Ricca 同时减速，恢复后死亡动作继续播放

### 场景: 编辑参数
- 当 在普攻配置的 Inspector 中调整卡肉持续秒数或共用播放倍率
- 则 此后有效命中应用调整后的数值，默认时长为 0.10 秒，默认倍率为原速的 5%

## R11 — 十波进度与通过判定

### 场景: 初始化战斗
- 当 City Demo 开始一局
- 则 Application 从第 1 波开始，使用各波独立的同屏生成上限、刷怪间隔和总敌人数，并提供当前波号与总波数 10，供屏幕顶部居中的 X/10 使用

### 场景: 累计击败
- 当 当前波的一只敌人 HP 首次归零
- 则 Application 将该敌人计入击败数。累计击败数达到配置总数且 Ricca 存活时通过该波

### 场景: 未成功生成或未被击败的实例离场
- 当 生成未成功确认或存活敌人提前移除
- 则 Application 在回收对应名额后允许补足配额，保持当前击败数

### 场景: 同一帧清波和死亡
- 当 同一帧达到通过条件且 Ricca HP 归零
- 则 Application 采用死亡状态及第 1 波状态，结束本局并取消待选奖励

## R12 — 每波奖励三选一（MODIFIED v0.0.1）

### 场景: 通过一波
- 当 Ricca 存活且 Application 确认任一波通过
- 则 Application 保持当前波号并停止生成和战斗输入，给出一组三张有效奖励。City Demo 的技能、普攻伤害和生命奖励同权。三类满足资格时共同进入同一无放回候选池，组合以类型和等级唯一，允许同类不同等级。没有可授予或升级技能或本局剩余 MP 低于 10 时排除技能候选，由属性奖励补足三张。面板接管鼠标，第 10 波标记最后奖励

### 场景: 有效奖励选择
- 当 玩家选择当前组的一个有效选项且尚未结算、Ricca 存活
- 则 Application 结算一次。生命奖励同量增加当前与最大 HP，攻击奖励增加普攻伤害。两种加成在本局可叠加且等级越高增量越大。技能奖励执行 R14 的授予或升级并保留已有确认通知。第 1 至 9 波结算后前进一波

### 场景: 无效选择
- 当 玩家重复点击、索引越界、选择过期组或已经离开选择阶段
- 则 Application 维持当前属性、技能、波次和待选状态

### 场景: 旧场景奖励
- 当 不含技能运行配置的旧场景请求波次奖励
- 则 Application 沿用其既有权重与占位行为

## R13 — 第十波通关结果

### 场景: 第十波领奖与通关
- 当 Ricca 通过且完成第 10 波的奖励选择
- 则 Application 进入通关状态并保持 10/10，停止生成，向界面提供通关及重开入口

### 场景: 通关后重新开始
- 当 玩家在通关状态点击重新开始且尚未发起本次重载
- 则 Application 接受一次重开，重新载入 Demo 并按 R9 开始新局

## R14 — 四槽装备与局内技能池（MODIFIED v0.0.1）

### 场景: 开始或重启一局
- 当 Demo 开始新局
- 则 Application 初始化四个空装备槽

### 场景: 有空槽时获得技能
- 当 当前局有空槽且玩家领取有效技能奖励
- 则 Application 将该卡锁定的一项未装备技能填入最左空槽，初始等级等于卡片等级。五项源技能均可在正常局内成为候选，动作变体归属同一个技能 ID

### 场景: 槽满后升级
- 当 四槽已满且领取有效技能奖励
- 则 Application 升级已装备的最低等级技能，同级选择最左槽，至少升一级，高等级卡可升至卡片等级，最高 Lv.3。在同样有效命中条件下，升级后实际伤害提高

### 场景: 技能目录或蓝量失去资格
- 当 清波时没有可授予或可升级技能，或本局剩余 MP 低于 10
- 则 Application 从仍有效的属性候选抽取三张奖励

### 场景: Ricca 死亡
- 当 Ricca 生命归零且本局失败
- 则 Application 终止在途选择和施放，清除本局技能状态

## R15 — 子弹时间技能选择（MODIFIED v0.0.1）

### 场景: 有可施放技能
- 当 Ricca 存活、处于可操控战斗阶段且可起手，玩家按 F，已装备可用技能且有至少 10 MP
- 则 Application 打开技能选择，并请求减速到此前的 20%，屏蔽战斗输入并允许鼠标选技

### 场景: 空槽或缺蓝
- 当 Ricca 存活、处于可操控战斗阶段且可起手，玩家按 F，当前无可施放技能，包括四槽为空、MP 低于 10 或资源不可用
- 则 Application 提供原速技能查看状态，禁用不可施放选项并给出对应反馈

### 场景: 确认有效施放
- 当 玩家点击当前选择中的可用槽位且施放检查通过
- 则 Application 消费本次选择和 10 MP，关闭面板并释放减速。Unity 恢复速度，按确认时的角色朝向和适用的方向变体播放源技能动画，点击不触发普攻

### 场景: 退出技能选择
- 当 按 F 或 Esc，失焦，Ricca 受到有效伤害，阶段切换或场景卸载
- 则 Application 结束选择，Unity 恢复该次仍受选择控制的时间设置。未接受施放时维持当前 MP

## R16 — 源技能施放与伤害盒（MODIFIED v0.0.1）

### 场景: 技能动作及特效
- 当 Application 接受本轮技能池中的一项施放
- 则 Application 发布当前施放标识和配置。Unity 播放已绑定源动作及适用的原有效果

### 场景: 有效伤害
- 当 在当前技能生效区间内，配置的技能盒或移动扫掠路径接触一个存活敌人的受击体
- 则 Application 按技能及等级结算伤害，一次施放对每个目标最多一次，目标归零纳入受伤、死亡和清波计数

### 场景: 无效伤害
- 当 盒体未接触、窗口外、同施放重复接触、或已失效的批次提交
- 则 Application 维持敌人 HP

### 场景: 中断在途动作
- 当 技能施放中的 Ricca 收到有效伤害或离开战斗
- 则 Application 取消在途动作并作废后续伤害

### 场景: 施放期间的输入
- 当 Ricca 正在施放技能时收到新的普攻或技能选择输入
- 则 Application 拒绝新的动作请求并维持当前施放状态

## R17 — 局内蓝量与固定施放成本

### 场景: 开局和重开
- 当 Demo 开始一局，包括死亡或通关后重开
- 则 Application 初始化满蓝，默认 MP 为 100。当前一局的 MP 仅根据有效施放扣减

### 场景: 接受技能
- 当 已装备技能可施放，当前 MP 至少为 10，且有效选择及动作源检查通过
- 则 Application 在施放事务内准确扣 10 MP，接受一次技能，蓝量最高以配置上限为准，最低为 0

### 场景: 拒绝或取消
- 当 MP 低于 10，或在施放被接受前发生取消、过期、重复请求和资源校验失败
- 则 Application 维持已有蓝量并拒绝对应的新施放

### 场景: 已接受施放后受击
- 当 已接受且已经扣蓝的技能被受击中断
- 则 Application 结束本次施放并维持本次扣减后的蓝量
