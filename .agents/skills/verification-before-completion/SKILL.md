# 完成前验证（Unity 版）

> 源包（Roblox）版本的前提是"无单测框架、无 CI"，所以只能靠 Play F5 肉眼观察。
> **Unity 有测试框架——这条必须升级**：能自动验的必须自动验，不能自动的必须留可回溯证据。

## 铁律

```
没有新鲜的验证证据，不许宣称完成。
```

"新鲜"= 在本轮改动**之后**取得的证据。上一轮的通过记录一律过期。

---

## 门控函数

在宣称任何状态或表达满意之前：

1. **确定**：什么证据能证明这个结论？（编译？测试？截图？diff？）
2. **获取**：实际执行——跑测试、跑编译、看 Profiler、截图
3. **阅读**：完整读输出（含 warning），不要只看最后一行
4. **判断**：证据是否支持结论？
   - 否 → **用证据说明实际状态**（"X 测试失败，报 Y"）
   - 是 → **带证据陈述**（"AC-2 通过：测试 `Buy_InsufficientFunds_Rejects` 绿，余额未变"）
5. **只有此时**才能下结论

跳过任一步 = 说谎，不是验证。

## 声明 → 证据（摘要；权威表在 `开发规范/验证与门禁.md` §2）

| 结论 | 需要的证据 | 不够格 |
|---|---|---|
| 编译通过 | `Unity -quit -batchmode -projectPath . -logFile -` 输出 0 error | "代码看着没问题" |
| 逻辑正确 | 对应 EditMode 测试绿 | "逻辑上应该对" |
| 数值正确 | 表驱动用例（边界/负值/溢出/NaN）全绿 | 手动点了几下 |
| 存档不丢 | 写入→读取→迁移 三段用例绿 | "保存过一次" |
| Bug 已修 | 先复现（红）→ 修 → 同一用例转绿 | "改了这行应该好了" |
| UI 正确 | 改前/改后截图 | "样式写对了" |
| 性能达标 | Profiler 截图 + 帧时间数字 | "感觉挺流畅" |
| 联机同步 | 两实例 PlayMode 或双机日志 | "单机测过" |
| 分层没破 | asmdef 校验通过 | "我没引 Presentation" |
| Phase 完成 | 逐条核对产物 + 验收标准 | 单个用例过了 |
| 可以归档 | L1 全绿 + 门禁 G1–G8 全部通过 | "审核说没问题" |

## 常见借口 vs 现实

| 借口 | 现实 |
|---|---|
| "逻辑上应该能行" | 去写/跑那条测试 |
| "我有信心" | 信心 ≠ 证据 |
| "就这一次不测" | 没有例外 |
| "编译过了就行" | 编译只证明类型对 |
| "上次测过是好的" | 代码又改了 = 证据过期 |
| "reviewer 说通过了" | 自己看 diff，独立核对 |
| "测试太慢，我手动看了一下" | 手动结果不算 L1，最多 L3，且要截图 |
| "换个说法这条规则就不适用" | 精神大于字面 |

## 证据写法（正/反例）

**测试**
```
✅ EditMode 全绿（42 passed / 0 failed），其中新增 5 条覆盖 AC-1..AC-4
❌ "测试应该没问题"
```

**Bug 修复**
```
✅ 先跑 `Buy_Concurrent_OnlyOneSucceeds` 复现失败（2 次发货）→ 加 requestId 幂等 → 重跑绿
❌ "加了幂等判断，应该好了"
```

**存档**
```
✅ 写入 v2 存档 → 用 v1 代码读取 → 触发迁移 → 字段完整（用例 `Save_MigrateV1ToV2` 绿）
❌ "加了版本号字段"
```

**表现层**
```
✅ 截图：1280×720 与 2560×1440 下按钮均居中未溢出（附两张图）
❌ "用了 Anchor，应该自适应"
```

**Phase 收尾**
```
✅ 重读 03-plan.md 的 12 项任务 → 逐项核对 → 11 完成 1 延期（记 05-issues.md#L12）
❌ "主要功能都做完了"
```

---

## 何时必须使用

- 任何"改好了 / 验证通过 / Phase 完成 / 可以归档"的声明
- 任何满意表达（"搞定""完美""这下没问题了"）
- `/workflow archive`、git commit、进入下一 Phase 之前
- 采信子代理结论之前（独立看 diff，不看它的措辞）

---

## 为什么这很重要

- 未验证的东西会被**归档进 `spec/` 成为"当前真相"**，后续所有迭代建立在假前提上
- AI 生成代码的最大风险不是"写得差"，而是**"看起来对"**——只有证据能区分
- 诚实底线：失败就说失败并附输出；跳过就说跳过；完成且验证了才平铺直叙说完成

---

## 底线

**验证没有捷径。** 跑测试、读输出、看 diff、截图，然后才能宣称结果。没有商量余地。
