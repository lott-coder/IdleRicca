# IdleRicca 美术风格

> 已确认方向 · 蓝金骑士  
> 2026-11-22

护甲和骑士徽章提供界面造型的参考。主色为深钴蓝和墨蓝，香槟金集中在轮廓、切角和命中反馈，象牙白用于关键数字。蓝珐琅用冷色亮面和暗面表现厚度，金属用窄高光和暗倒角表现质感。红色留给生命和危险状态。

## 视觉语言

| 元素 | 表现 |
|---|---|
| 轮廓 | 细长、带切角的外框，端部收尖。徽章使用清楚的剪影和少量分面。 |
| 材质 | 缎面香槟金配蓝珐琅。以窄高光和一到两级暗面表现边缘，保持装饰集中。 |
| 色彩 | 象牙白 `#FFF6DA` 显示主数字，暖金 `#F5CF8D` 强调次级信息与命中反馈。墨蓝底槽区分填充与空槽。 |
| 文字 | 战斗数字用粗斜体和深墨描边，标签缩小一级。明亮场景上用局部阴影维持读数。 |
| 动效 | 用短促的金光和数字强调表现有效命中。金光衰减后，数字和计时条继续提供状态信息。 |

## 首批应用

战斗 HUD 左上以原创枪尖盾徽连接 HP 和 MP。HP 用暖红填充并展示生命数值，MP 用更短、更细的钴蓝槽。右侧以象牙白斜体数字、渐隐阴影和细金色计时条表现连击。
