# 编码约定（Unity / C#）

> 适用范围：`Assets/**/*.cs`。与 [架构.md](架构.md) 的 asmdef 分层冲突时，以架构为准。

---

## 1. 命名

| 元素 | 规则 | 示例 |
|---|---|---|
| 类型 / 方法 / 属性 / 事件 | PascalCase | `InventoryService`、`TrySpend`、`OnDataReady` |
| 接口 | `I` + PascalCase | `ISaveStore` |
| 局部变量 / 参数 | camelCase | `itemId`、`deltaTime` |
| 私有字段 | `_` + camelCase | `_inventory`、`_isReady` |
| 常量 / 静态只读 | PascalCase（不用全大写） | `MaxStack`、`DefaultTimeout` |
| 异步方法 | `Async` 后缀 | `LoadAsync` |
| 布尔 | `is/has/can/should` 前缀 | `isLoaded`、`canAfford` |
| 事件处理器 | `On` + 事件名 | `OnInventoryChanged` |
| 泛型参数 | `T` + 描述 | `TItem` |

**文件名 = 主类型名**，一个文件一个 public 类型。`partial` 仅用于生成代码。

> 与 Roblox 版的差异：源包用 `UPPER_CASE` 常量，Unity/C# 生态惯例是 PascalCase。**遵循本引擎生态，不要照搬。**

## 2. 序列化与 Inspector

```csharp
// ✅ 正确：私有字段 + SerializeField，Inspector 可配，代码不可外改
[SerializeField] private float _moveSpeed = 5f;

// ❌ 禁止：public 字段（污染 API 且无校验）
public float moveSpeed = 5f;

// ✅ 需要外部只读时
public float MoveSpeed => _moveSpeed;
```

- 引用型字段优先**直接序列化引用**（拖拽），禁止字符串路径 + 运行时查找
- 需要分组/校验时用 `[Header]`、`[Range]`、`[Tooltip]`、`OnValidate()`
- `ScriptableObject` 用于**配置数据**，不得承载运行时可变状态（运行时会污染资产）

## 3. 生命周期

| 规则 | 说明 |
|---|---|
| `Awake` 只做自身初始化 | 不查场景、不依赖他人 |
| `Start` 做一次性绑定 | 仍不得假设数据已就绪（见架构 §4） |
| `Update` / `LateUpdate` / `FixedUpdate` 内**禁止**分配 | 禁 `new`、禁字符串拼接、禁 LINQ、禁 `GetComponent` |
| 订阅与退订成对 | `OnEnable`/`OnDisable` 或 `Dispose`，**不得**只订阅不退订 |
| `Destroy` 前收尾 | 停协程 → 退订 → 释放句柄 |

```csharp
// ✅ 成对
private void OnEnable()  => _inventory.Changed += OnInventoryChanged;
private void OnDisable() => _inventory.Changed -= OnInventoryChanged;

// ✅ 更优：CancellationToken 让异步可取消
private readonly CancellationTokenSource _cts = new();
private void OnDestroy() { _cts.Cancel(); _cts.Dispose(); }
```

**禁止**：`Invoke("MethodName", 1f)`（字符串反射）、`SendMessage`、`StartCoroutine` 里无限的 `while(true)` 无退出条件。

## 4. 分层纪律

| 层 | 允许 | 禁止 |
|---|---|---|
| Domain | 纯计算、`record`/`class` 模型、规则 | `UnityEngine`、`Debug.Log`、`Time.deltaTime`（用参数传入 dt） |
| Application | 编排、唯一写入口、事务 | `MonoBehaviour`、`Input`、`Find*` |
| Infrastructure | IO、网络、序列化 | 业务规则、数值公式 |
| Presentation | 读状态、发 Command、表现 | 直接改状态字段、写存档 |

**时间的传递**：Domain 层不得读 `Time.time`，必须由调用方传 `float deltaTime` 与 `double nowUnix`——这是让规则可单测的前提，也是"时间可作弊"的防线。

---

## 5. 数值与输入净化

所有来自外部（玩家输入、存档、网络、配置表）的数值必须先净化：

```csharp
public static float Finite(float value, float fallback) =>
    float.IsNaN(value) || float.IsInfinity(value) ? fallback : value;

public static int ClampInt(long value, int min, int max) =>
    (int)Math.Clamp(value, min, max);
```

规则：
- 读任何外部数值 → 先 `Finite` / `Clamp`，再做业务
- 货币/经验用 `long` 或 `decimal`，**禁止 `float`**
- 展示层单独做缩写格式化（K/M/B），不得在结算层截断
- 时间用 `DateTimeOffset.UtcNow.ToUnixTimeSeconds()` 的绝对时间戳，**禁止本地时间**

## 6. 异常与日志

| 场景 | 做法 |
|---|---|
| 可预期的业务失败 | 返回结果对象 `Result<T>`（`Ok`/`Fail(reason)`），**不用异常** |
| 不可预期的编程错误 | 抛异常，让 CI/测试暴露 |
| 存档/网络 IO 失败 | 捕获 → 显式失败 → 阻断流程并提示（禁止静默降级） |
| 日志 | `Debug.Log` 仅用于开发期；正式代码走 `ILogger` 抽象，分级 `Info/Warn/Error` |

**禁止**：`catch (Exception) { }` 空捕获；`catch` 后继续执行而不改变状态。

---

## 7. 异步

- 用 `async/await` + `Awaitable`（Unity 6）或 `UniTask`；**禁止** `.Result` / `.Wait()` 同步阻塞
- 所有 `async void` 仅允许出现在 Unity 事件入口（`Start`/按钮回调），且内部必须 `try/catch`
- 异步方法必须接受 `CancellationToken`，并在对象销毁时取消
- 超时一律显式：`await task.WaitAsync(TimeSpan.FromSeconds(10), ct)`

---

## 8. 注释与可读性

- **注释中文，标识符英文**（沿用源包团队约定）
- 注释解释**为什么**，不解释**是什么**
- 公开 API 必须 XML 文档注释：
  ```csharp
  /// <summary>尝试扣除金币；余额不足时不做任何变更。</summary>
  /// <returns>成功返回 Ok；余额不足返回 Fail("INSUFFICIENT")。</returns>
  ```
- 每个"魔法数"必须有来源注释（策划表格 / 公式 / 需求编号 R{n}）
- 禁止被注释掉的死代码进主干（用 git 找回）

---

## 9. 禁止清单（一票阻断）

- ❌ `GameObject.Find` / `FindObjectOfType` / `Resources.Load`（运行时按名/按路径查找）
- ❌ 反射式依赖注入、字符串事件名、`SendMessage`
- ❌ `Update` 内分配（`new`/LINQ/字符串拼接/`GetComponent`）
- ❌ `catch (Exception) {}` 空捕获
- ❌ 存档载入失败静默用默认值继续
- ❌ `float` 存货币或经验
- ❌ `public` 字段做序列化
- ❌ 跨层反向依赖（`Domain` → `Presentation` 等，asmdef 会报错，不得绕过）
